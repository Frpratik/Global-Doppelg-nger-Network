# DOPPEL AI Model Card

## Model Overview
- **Model Family**: ArcFace / MobileFaceNet Feature Extractor
- **Embedding Dimensionality**: 512 Floats (L2 Normalized)
- **Input Dimensions**: $112 \times 112 \times 3\text{ (RGB)}$
- **Target Task**: Metric Learning & Topological Feature Space Distance
- **License**: MIT / Open-Source Academic License

## Intended Use
- Voluntary doppelgänger and visual twin discovery among consenting participants.
- Visual resemblance search within closed, opt-in networks.

## Prohibited Use
- Unconsented mass surveillance or facial identification.
- Scraping public internet or social media imagery.
- Law enforcement or unconsented tracking.
- Making claims regarding biological paternity, DNA kinship, or genetic ancestry.
