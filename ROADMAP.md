# DOPPEL Product & Engineering Roadmap

## Phase 1 (Shipped - MVP v1.0)
- [x] Single-face detection & quality verification engine (`face_quality.py`).
- [x] 512-dimensional ArcFace/ONNX normalized embedding pipeline.
- [x] High-performance VectorStore abstraction with cosine ANN search.
- [x] Dual consent architecture and instant biometric purge endpoint.
- [x] Next.js 14 cybernetic dark UI, animated canvas radar, and live webcam enrollment.
- [x] Benchmark suite and 60-persona synthetic dataset seeder.

## Phase 2 (Near-Term Scaling)
- [ ] Distributed Qdrant / Milvus vector clustering for 1,000,000+ profiles.
- [ ] Asynchronous background job queue for heavy batch enrollments using Celery/Redis.
- [ ] Geo-proximity radius matching with OpenStreetMap / Leaflet integration.
- [ ] Interactive 3D vector manifold visualization with Three.js / WebGL.

## Phase 3 (Ecosystem Expansion)
- [ ] Doppel Mobile App (React Native / iOS & Android camera kit).
- [ ] Verified celebrity lookalike & historical portrait exploration mode.
- [ ] Zero-Knowledge Proof (ZKP) biometric identity verification.
